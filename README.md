# Mathematical-Programming
FAST University: Applying Mathematical Concepts Through C-Programming

# Overview of Mathematical Operations

This assignment focuses on the practical implementation of mathematical operations and numerical problem-solving using C programming. It includes calculating average speed, displaying patterns, swapping variable values, calculating salary tax and net income, and distributing currency into the minimum number of coins. It also involves solving quadratic equations by determining their real or complex roots. Overall, these tasks demonstrate fundamental arithmetic operations, variables, input/output, and conditional logic.

1.Speed: Calculates the average speed using distance and time.
2.Pattern: Displays a triangle pattern using asterisks.
3.Swapping: Exchanges the values of two variables using a temporary variable.
4.Taxation: Calculates the tax amount and net salary based on the given percentage.
5.Distribution: Distributes a fixed amount of pennies into the minimum number of coins.
6.Quadratic: Calculates the real or complex roots of a quadratic equation using its coefficients.

gcc task1.c -o task1 && task1.exe
